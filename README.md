深紫外光刻物镜中强曲率透镜增透膜设计受多物理场条件限制，存在大角度斜入射偏振分裂、
径向反射不均、多层薄膜残余应力等难题。为此，本文构建一种深度神经网络代理模型结合拟牛
顿局部精修的两阶段多目标协同优化框架。以熔石英基底七层膜系为研究对象，在经典氟化镁
（MgF2）和氟化镧（LaF3）交替结构内增设 GdF3、AlF3 功能层，搭建渐进导纳阶梯并实现薄
膜拉压应力自补偿。优化过程聚焦全口径平均反射率与空间均匀性，同时评估偏振分裂、热光漂
移、残余应力等约束指标。先通过代理模型快速筛选参数，再采用传输矩阵法精确求解。优化所
得膜系在宽入射角范围内实现低反射与高均匀性、弱偏振差与低热漂特性，残余应力远低于透镜
形变阈值。蒙特卡洛虚拟制造分析证明该设计工艺稳定性好、良率高，并标示出工艺管控关键膜
层。研究表明，多材料层序搭配与代理模型加速优化相结合，可解耦高曲率元件光学性能与力学
约束的冲突，为高端光刻设备超精密薄膜设计提供理论与工程参考。
